# Spotter Freight Rate ML Assessment

This repository contains a reproducible, dependency-constrained solution to the
Spotter freight-rate machine-learning assessment. The full run instructions and
modeling rationale will be added after the analysis pipeline is complete.

## Environment

```powershell
poetry install
poetry run python -c "import matplotlib, numpy, pandas; print('Environment OK')"
```

Dependencies intentionally match the constraints in `requirements.txt`.
